# Agenda Telefônica — Atividade 1

Aplicação monolítica simples (Flask + Jinja) para cadastrar, listar e consultar contatos.
Os contatos ficam salvos em `contatos.json` — sem banco de dados, sem deploy.

## Como rodar

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask run
```

Acesse http://localhost:5000
